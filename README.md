# House-Price-Prediction-ML
House price prediction using machine learning
House Price Prediction using Machine Learning

Project Overview

This project predicts house sale prices using machine learning. It includes data analysis, feature importance, model comparison, cross-validation, and model evaluation.

Technologies Used

- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Google Colab
- AI Tools

Models Compared

- Linear Regression
- Ridge Regression
- Random Forest
- Gradient Boosting

Best Model

Gradient Boosting (selected using 5-fold cross-validation).

Test Results

- Mean Absolute Error (MAE): $16,922.49
- Root Mean Squared Error (RMSE): $30,265.12
- R² Score: 0.8806

Example Prediction

- Actual house price: $154,500.00
- Predicted house price: $142,549.85
- Absolute error: $11,950.15

Project Files

- Jupyter Notebook: complete analysis and model training
- "house_price_model.pkl": saved trained model
- "model_metrics.json": evaluation metrics
- "cross_validation_results.csv": cross-validation results
- "feature_importance.csv": feature importance results
- "model_comparison.csv": model comparison results

How to Run

1. Download the project notebook from this repository.
2. Open it using Google Colab.
3. Upload the required dataset when prompted.
4. Run the notebook cells in order.
